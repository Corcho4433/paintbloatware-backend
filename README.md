# paintbloatware-backend

To install dependencies:

```bash
bun install
```

Para levantar la base de datos:

- Instalar docker-compose
- start y enable docker
- sudo docker-compose up -d
- bun run migrate
- bun run generate
- bun run seed
- bun run dev
